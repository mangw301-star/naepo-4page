# 내포더봄치과 홈페이지 — 4페이지 구성

`index_24.html` 원페이지를 4개 페이지로 분할하고, 지적된 디자인 문제를 반영한 버전입니다.

## 파일 구성

```
index.html        홈 — 브랜드, 병원소개, 자연치아 보존, 설명형 진료
doctor.html       의료진 소개 — 원장 프로필, 전문의 수련 과정, 자격증
treatment.html    진료과목 — 5개 과목, 디지털 임플란트, 정밀장비, 턱관절
visit.html        진료공간 · 오시는 길
privacy.html      개인정보처리방침 (초안 — 확인 필요)
style.css         공용 스타일시트
app.js            공용 스크립트
sitemap.xml       검색엔진 제출용
robots.txt
```

### 페이지가 답하는 질문

| 파일 | 질문 | 노리는 검색어 |
|---|---|---|
| `index.html` | 여긴 어떤 치과인가 | 내포 치과, 홍성 치과 |
| `doctor.html` | 누가 진료하나 | 홍성 치과보존과 전문의, 내포 치과 전문의 |
| `treatment.html` | 내 증상 여기서 되나 | 홍성 신경치료, 내포 임플란트, 홍성 턱관절 |
| `visit.html` | 어떻게 가나 | 내포더봄치과 위치, 주차 |

전부 같은 폴더에 두고 열면 그대로 동작합니다. 빌드 도구 없이 GitHub Pages에 바로 올릴 수 있습니다.

## 반드시 채워야 하는 것

### 1. 외부 링크 — `app.js` 맨 위 4줄만 고치면 3개 페이지 전부 반영됩니다

```js
var LINKS = {
  booking : '',   // 네이버 예약
  place   : '',   // 네이버 플레이스
  blog    : '',   // 네이버 블로그
  kakao   : ''    // 카카오톡 채널
};
```

비워두면 해당 버튼은 **자동으로 숨겨집니다.** 죽은 링크가 노출되지 않게 한 안전장치인데,
지금 상태로는 모바일 하단바에 전화·오시는 길 2개만 보입니다. 개발자도구 콘솔에
어떤 링크가 비어 있는지 경고가 찍힙니다.

### 2. 도메인 — naepothebom.co.kr (GitHub Pages 커스텀 도메인)

루트의 `CNAME` 파일(내용: `naepothebom.co.kr` 한 줄)이 도메인을 결정합니다.
**삭제하거나 덮어쓰지 마세요** — 없어지면 사이트가 github.io 주소로 되돌아갑니다.

주소가 바뀌는 날이 오면 아래 파일의 `https://naepothebom.co.kr/` 를 일괄 치환하세요:
canonical · og:url · og:image · JSON-LD (index/doctor/treatment/visit/privacy.html), sitemap.xml, robots.txt.
DNS(가비아: A 레코드 4개 → 185.199.108~111.153, www CNAME → mangw301-star.github.io)가
먼저 새 주소를 가리킨 뒤에 CNAME 파일을 바꿔야 접속이 끊기지 않습니다.

### 3. 나머지 치환 토큰

| 토큰 | 위치 | 넣을 값 |
|---|---|---|
| `REPLACE-POSTAL` | 4개 페이지 JSON-LD | 실제 우편번호 (기존 `00000` 은 로컬 SEO에 마이너스였습니다) |
| `REPLACE-BIZNO` | 모든 푸터 | 사업자등록번호 |
| `REPLACE-DATE` | privacy.html | 개인정보처리방침 시행일 |

### 4. 이미지

`.ph` 클래스가 붙은 자리가 아직 비어 있는 곳입니다. 사진을 넣을 때는:

```html
<!-- 전 -->
<div class="ph r-4x3 dark"><span>대기실</span></div>

<!-- 후 -->
<div class="ph r-4x3 dark has-img" role="img" aria-label="대기실"
     style="background-image:url('interior-waiting.jpg')"></div>
```

필요한 파일 (전부 ASCII 파일명으로 바꿨습니다 — 기존 한글 파일명은 서버에 따라 깨집니다):

```
logo.png  hero.mp4  hero-poster.jpg  og-image.jpg(1200×630)  doctor-profile.jpg
treat-endo.png  treat-restore.png  treat-implant.png  treat-prostho.png  treat-general.png
equip-microscope.png  equip-scanner.png  equip-cbct.jpg  equip-cadcam.png
digital-implant.png  tmj-treatment.png
```

**자격증 2장은 A4 세로(1:1.414)로 비율을 바꿨습니다.** 실물이 가로형이면
`style.css` 의 `.ph.r-a4` 대신 `.ph.r-4x3` 을 쓰세요. 안 맞으면 직인이 잘립니다.

### 5. 네이버 지도

`visit.html` 의 `<!-- ▼ 네이버 지도 삽입 방법 -->` 주석에 절차를 적어뒀습니다.
지금은 자리만 잡혀 있습니다.

## 반영한 디자인 수정

| 항목 | 이전 | 이후 |
|---|---|---|
| 골드 사용처 | 51곳 | **22곳** (라벨 / 헤드라인 em / 주 CTA / 활성 상태로만 제한) |
| 서체 | Cormorant + Noto Serif KR + Noto Sans KR + Pretendard(미사용) | **나눔명조 + Pretendard** 2종, 둘 다 실제 사용 |
| font-size 고유값 | 31개 | 토큰 8단계 + 소형 UI값 몇 개 |
| 데스크톱 재정의 블록 | 20줄 개별 오버라이드 | **삭제** (clamp 유동 스케일로 대체) |
| 본문 폭 | 42em (한 줄 40자↑) | **32em** (30자 내외) |
| 루트 폰트 | `19px` 고정 | `100%` — 사용자 브라우저 설정 존중 |

| 히어로 오버레이 | `.78` (영상이 안 보임) | `.72→.14` 그라디언트 + text-shadow |
| 히어로 높이 | `100vh` (iOS 점프) | `100svh` |
| 노이즈 오버레이 | 전 기기 | 모바일 제외 (스크롤 성능) |

| 제목 위계 | h1 → h3 (h2 건너뜀) | h1 → h2 → h3 정상화 |
| 죽은 코드 | `reduce` 변수, `data-autoplay`, 미사용 슬라이더 CSS | 제거 |

### 그 외

- **진료과목 캐러셀 해체** — 5개를 세로로 펼치고 상단에 앵커 6개. 숨어 있던 4/5가 보입니다.
- **진료공간 투어에 스와이프 추가** — 터치로 넘어가고, 화면 밖 슬라이드는 `inert`로 스크린리더에서 숨김.
- **스크롤스파이 교체** — 파일명 기준으로 현재 페이지를 표시하고, 같은 페이지 앵커만 추적합니다.
- **의료진 페이지 분리** — 원장 프로필 / 전문의 수련 과정 / 자격증을 `doctor.html` 로 독립.
  홈에는 카드로 연결되고, 원장명·전문의 자격은 카드 설명에 남겼습니다.
- **페이지마다 하단 CTA 블록** 추가.
- 하위 페이지는 영상 없는 38vh 배너 + 브레드크럼.
- `prefers-reduced-motion` 실제 적용 (기존엔 변수만 선언하고 안 썼습니다).
- 키보드 포커스 링, 본문 바로가기 링크, 인쇄 스타일 추가.

## 의료법 관련해서 손댄 문구

원장님 이름이 걸리는 부분이라 다음 4가지를 조정했습니다. **최종 판단은 확인해 주세요.**

| 이전 | 이후 | 이유 |
|---|---|---|
| "전체 치과의사 중 **단 3%**" | "치과보존과는 자연치아를 살리는 치료를 전담하는 전문 과목입니다" + 각주에 인원 수만 사실 기재 | 희소성 강조는 의료법 제56조 비교광고 소지 |
| "**과잉 없는** 치료" | "지금 필요한 것부터" | 타 기관 과잉진료를 전제로 읽힘 (비방광고) |
| "**불필요한 발치**를 줄일 수 있습니다" | "발치 여부를 더 신중하게 판단할 수 있습니다" | 위와 같음 |
| "네이버 플레이스 · **후기와** 예약" | "네이버 플레이스 · **위치와** 예약" | 치료경험담 유도는 회색지대 |

3% 각주는 2021년 자료입니다. 최신 수치로 갱신하시거나 연도를 명시한 채로 두세요.

`privacy.html` 은 일반 양식 기반 초안입니다. 예약 시스템·문자 발송 대행 등
**수탁업체가 있으면 처리위탁 항목을 반드시 추가**해야 합니다. 페이지 안에
확인 요청 박스를 넣어뒀으니 보완 후 삭제하세요.

## 아직 안 한 것

- **`.certs` 실물 비율 확인** — 자격증 스캔 받아보고 결정
- **`hero.mp4` 모바일 경량화** — `preload="metadata"` 로 낮춰뒀지만, 모바일에서
  영상 대신 `hero-poster.jpg` 만 쓰는 게 LCP에는 더 낫습니다. 영상 용량 보고 판단하세요.
- **FAQ 섹션** — `FAQPage` 스키마를 붙이면 "홍성 신경치료" 같은 롱테일에서
  리치 스니펫이 노출될 수 있습니다. treatment.html 하단이 자리로 적당합니다.
- **비급여 진료비 안내** — 원내 게시가 법적 의무이고 홈페이지는 아니지만,
  임플란트·보철을 다루면서 가격 언급이 전무한 건 전환율 측면에서 아쉽습니다.
