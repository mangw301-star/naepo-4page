# assets — 촬영 결과물 넣는 폴더

전문 촬영이 끝나면 아래 파일명 그대로 이 폴더에 넣기만 하면
홈페이지 첫 화면 영상이 자동으로 재생됩니다. (코드 수정 불필요)

| 파일명 | 용도 | 권장 사양 |
|---|---|---|
| `hero-video.webm` | 첫 화면 배경 영상 (주 재생용) | 1920×1080, 10~20초 루프, 소리 없음 |
| `hero-video.mp4` | 위와 같은 영상 (구형 브라우저 호환용) | H.264, 위와 동일 |
| `hero-poster.webp` | 영상 로드 전·실패 시 정지 화면 | 영상의 대표 프레임 1장 |

- 색감: 따뜻한 중성 색온도. 피부색이 노랗거나 초록빛으로 치우치지 않게.
- 구도: 화면 왼쪽에 제목이 올라가므로 주요 인물·장면은 중앙~오른쪽에 배치.
- 크롭이 어긋나면 style.css의 `--hero-focus`(PC) / `--hero-focus-m`(모바일) 값만 조정.
